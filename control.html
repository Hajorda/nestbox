How to connect (once, about 10 minutes)
 
    
  
  1. Open console.cloud.google.com, create a project (any name), then APIs & Services → Library → Gmail API → Enable.
    2. 
  
  2. OAuth consent screen: User type External, app name anything, your Gmail as support and developer email. Add the scope .../auth/gmail.readonly. Under "Test users" add your own Gmail. At the end press Publish app (otherwise Google logs you out every 7 days; for a private tool the "unverified app" warning is fine).
    3. 
  
  3. Credentials → Create credentials → OAuth client ID → Desktop app. Download the JSON and save it in the project folder as gmail_client.json.
    4. 
  
  4. In a terminal in the project folder run python3 mail_link.py connect, sign in, press Continue on the "unverified" screen and allow read-only access.
    5. 
  
  5. Come back here and press "Check inbox now". Only read access is requested: the program cannot send, delete or change mail. Mail text stays on this Mac.
